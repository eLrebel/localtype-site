LocalType help

Most issues can be diagnosed without sending any snippet or autofill content.

Before contacting support

  1. Open chrome://extensions and confirm LocalType is enabled.
  2. Open LocalType → Manage → Diagnostics → Run self-check.
  3. If automatic expansion is off, open the popup and choose Enable websites.
  4. Refresh a page that was already open when LocalType was updated.
  5. Check whether LocalType is paused on the current website.

What to include in a bug report

  • LocalType version
  • Chrome version
  • Website/editor where the issue occurred
  • The trigger type used (Space, punctuation, Enter, or Tab)
  • Whether the issue also occurs in a basic textarea

Do not send passwords, OTPs, payment details, private snippets, or sensitive autofill values in a support report.

Support contact

The monitored support email must be added to the Chrome Web Store listing before public submission. Until then, this page intentionally does not publish an unmonitored or invented address.
