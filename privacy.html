PRIVACY POLICY

Local-first by design.

LocalType is a Chrome extension for reusable text shortcuts and explicit form autofill. Its core features work without a LocalType account or cloud service.

Information LocalType handles

LocalType may handle information that you choose to save, including text snippets and optional autofill profile fields such as name, email address, phone number, company, job title, postal address, country, and website.

For automatic text expansion, LocalType examines the editable text immediately around your typing cursor to determine whether it matches a shortcut. This matching is performed locally on your device.

LocalType also stores settings, paused website hostnames, local usage counters, an internal schema version, and a random installation identifier in Chrome extension storage.

How the information is used

Saved snippets are used to expand shortcuts that you type. Autofill profile data is inserted into a page only after you explicitly press Fill. Paused website hostnames are used only to remember sites on which you chose to disable LocalType.

Where information is stored

In the public-beta build, snippets, profiles, settings, paused-site rules, counters, and related extension state are stored locally in Chrome extension storage. LocalType does not operate a cloud database containing your snippets or autofill profiles.

Website access

Broad HTTP/HTTPS website access is optional. It is off on a fresh install and is requested only after you choose to enable automatic website expansion.

Website access lets LocalType run its local expansion engine in editable fields, detect saved shortcuts, and replace them with your saved text. LocalType does not use this access to build or transmit a browsing-history database.

Sensitive fields

LocalType is designed to avoid password, passcode, OTP, verification-code, payment-card, CVV/CVC, and common bank-account fields. Do not use LocalType as a password manager or secrets vault.

Backups

You can export a plain JSON backup or create a password-encrypted backup. Encrypted backups use AES-GCM with a password-derived key. The backup password is not stored by LocalType.

Backup files are created locally and are under your control. Plain JSON backups are human-readable and should be protected accordingly.

Analytics, advertising, and third parties

The v0.6.3 public-beta build contains no analytics SDK, telemetry endpoint, advertising, affiliate injection, cloud sync, external AI/API calls for text expansion, or remotely hosted JavaScript.

LocalType does not sell user data and does not use user data for personalized or interest-based advertising.

Data sharing

The public-beta build does not transmit your snippets, autofill profile contents, or editable page text to the LocalType developer. Information you intentionally insert into a website is naturally visible to that destination website after insertion.

Access, correction, and deletion

You can edit or delete snippets and autofill profiles in LocalType settings. You can also erase LocalType productivity data from the Backup & privacy section. Removing the extension causes Chrome to remove its local extension storage according to Chrome's platform behavior.

Limited Use

LocalType's use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

LocalType uses handled data only to provide or improve its disclosed user-facing functionality and related security/operational behavior. It does not transfer user data for advertising, data-broker, lending, or credit-worthiness purposes.

Sandbox purchase and activation testing

The public-beta extension does not process payments. This website offers sandbox testing of a future Pro edition. Paddle handles test checkout data. When you request activation, the licensing service hosted on Cloudflare receives your purchase email, Paddle transaction ID, and random installation identifier to verify the purchase and manage device slots. It stores transaction identifiers, purchase status, and installation activation records; it does not receive your snippets or autofill profiles. Payment-card credentials are not stored by the extension or licensing service. Real purchases are not available yet.

Changes to this policy

Material changes to LocalType's data practices will be reflected in this policy and, where required, disclosed in the extension before the changed practice is used.

Contact

For support or privacy questions, use the current support contact published on the LocalType Chrome Web Store listing and the LocalType support page.
